# NavBox · 可自定义的个人网址导航

基于 **EdgeOne Pages(Makers) + KV 存储** 的全栈导航页，源码可直接推送到 GitHub 部署，无需自建服务器、无需数据库。

带管理员后台，前台自适应手机与电脑屏幕。

---

## 功能一览

### 前台导航页

- 按分组展示书签，卡片式布局，自动适配手机 / 平板 / 桌面
- 实时搜索（匹配名称、网址、描述、分组名），支持快捷键 `/` 或 `Ctrl+K`
- 分组可折叠，折叠状态本地记忆
- 明暗主题：跟随系统 / 强制浅色 / 强制深色，用户可一键切换
- 顶部显示站点标题、副标题与实时时钟

### 书签

| 能力 | 说明 |
|---|---|
| 透明度与背景可调 | 卡片不透明度 0–100%、背景色、毛玻璃强度、圆角、文字色均可在后台调节，前台实时预览 |
| 图标自动抓取 | 默认自动抓取网站 favicon，按 `favicon.im → icon.horse → Google → 站点/favicon.ico` 多级回退 |
| 抓取失败降级 | 全部图标源失败时，自动用书签名称首字生成彩色文字图标 |
| 自定义图标 | 可为单个书签指定图标地址，或直接上传本地图标（自动压缩为 base64 内嵌） |
| 公开 / 私密 | 私密书签在接口层过滤，仅管理员登录后可见，并带「私密」角标 |
| 分组 | 每个书签归属一个分组，可跨分组移动 |
| 排序 | 后台拖拽或 ↑↓ 调整书签顺序，顺序持久化到云端 |
| 点击统计 | 记录每个书签的点击次数（弱一致，尽力统计） |

### 分组

- 新建 / 重命名 / 删除分组，可设置 emoji 图标
- **分组排序**：拖拽或 ↑↓ 调整，决定前台展示顺序
- 删除有书签的分组时二次确认，可选择连同书签删除

### 管理后台设置

1. **背景自定义**：渐变色（8 个预设 + 自定义 CSS）／图床直链／上传图片（存 KV），并可调节模糊、亮度、暗色遮罩
2. **书签分组排序**：见上
3. **书签导入与导出**：
   - 导出 JSON（完整备份，含设置与背景）或 HTML（Netscape 标准书签格式，可导入 Chrome/Edge/Firefox）
   - 支持「仅公开」或「含私密」两种导出范围
   - 导入支持 JSON 与浏览器 HTML，提供**合并**（按网址去重追加）与**覆盖**两种模式
4. **管理员名称与密码修改**：PBKDF2-SHA256 加盐哈希，改密后其他设备会话全部失效
5. **WebDAV 定时 / 手动备份**：见下方专节

## 技术架构

```
浏览器
  │
  ├── 静态资源（public/）        →  EdgeOne CDN 直接返回
  │
  └── /api/* 请求                →  Edge Functions（edge-functions/api/[[default]].js）
                                          │
                                          └── KV 命名空间（绑定变量名 NAV_KV）
```

- **零构建**：前端是原生 HTML/CSS/JS，无打包步骤，改完即部署
- **单文件后端**：全部 API 集中在一个 Edge Function 中，自带路由分发
- **无外部依赖**：不引入任何 npm 运行时包，仅用 Web 标准 API（Web Crypto、Fetch、Headers）

## 部署步骤

### 一、开通并绑定 KV（必做，否则接口全部返回 503）

> KV 目前为白名单能力，需先申请开通。免费版单账户容量 1GB。

1. 打开 [EdgeOne Makers 控制台](https://edgeone.ai/pages)，在顶部导航点击 **KV Storage → Apply now**
2. 填写申请理由（例如：个人网址导航站点，需存储书签与配置数据）后提交，等待审批通过
3. 审批通过后，点击 **创建命名空间**，填一个有业务含义的名字，例如 `navbox_kv`
4. 创建项目后进入 **项目 → KV 存储 → 绑定命名空间**：
   - 选择刚创建的命名空间
   - **变量名填 `NAV_KV`**（代码会优先识别这个名字；若你填了别的名字，代码也会自动扫描具备 KV 接口的绑定，但建议保持一致）

### 二、部署方式（三选一）

#### 方式 A：关联 GitHub 仓库（推荐，推送即自动部署）

1. 把本项目推送到你的 GitHub 仓库
2. 控制台 **项目 → Create project → 导入 Git 仓库**，选择该仓库
3. 构建设置确认：
   - 输出目录：`public`
   - 构建命令：留空
   - 安装命令：留空
4. 按「一」完成 KV 绑定，然后部署

之后每次 `git push` 到默认分支都会自动重新部署。此方式下**不需要** `.github/workflows/deploy.yml`，可删除以免重复部署。

#### 方式 B：GitHub Actions 自动部署

仓库已内置 `.github/workflows/deploy.yml`。

1. 在 EdgeOne 控制台 **API Token** 页面创建一个 Token
2. GitHub 仓库 **Settings → Secrets and variables → Actions → New repository secret**
   - 名称：`EDGEONE_API_TOKEN`
   - 值：刚创建的 Token
3. 修改 `.github/workflows/deploy.yml` 中的 `EDGEONE_PROJECT_NAME` 为你的项目名
4. 推送到 `main` 分支即自动部署

#### 方式 C：命令行手动部署

```bash
npm install -g edgeone      # 安装 CLI
edgeone login               # 登录（选择 Global 或 China）
edgeone makers link         # 关联项目，输入项目名；也用于把 KV 与环境变量同步到本地
edgeone makers deploy       # 部署到生产环境
edgeone makers deploy -e preview   # 或部署到预览环境
```

### 三、部署后首次使用

1. 访问你的站点地址，点击右上角 **⚙** 打开后台
2. 用默认账号登录：`admin` / `admin123`
3. **立即进入「账号」标签页修改密码**
4. 首次访问时系统会自动写入 3 个示例分组和 9 条示例书签，可在「书签」「分组」标签页里删改

## WebDAV 备份详解

### 配置

后台 → **备份** 标签页填写：

| 字段 | 说明 |
|---|---|
| WebDAV 地址 | 例：坚果云 `https://dav.jianguoyun.com/dav/`；Nextcloud `https://你的域名/remote.php/dav/files/用户名/` |
| 备份目录 | 默认 `/navbox-backup`，不存在会自动创建 |
| 用户名 | 你的网盘账号 |
| 密码 | ⚠️ **坚果云等服务必须用「应用密码」**，直接用登录密码会返回 401 |

保存后可点「测试连接」验证。

> 密码只存在你自己的 KV 里，**不会**写进导出的备份文件，也不会在接口响应中回显。

### 两种「定时」机制

**① 流量驱动自动备份（推荐，无平台限制）**

勾选「启用自动备份」即可。原理：有访客打开站点时，后端检查距上次备份是否已超过设定间隔（最小 1 小时），超过则在后台异步执行一次备份，不阻塞页面响应。

- 优点：可做到小时级，无需任何额外配置
- 限制：站点完全无人访问时不会触发

**② 平台定时任务（cron）**

在 `edgeone.json` 中加入 `schedules` 配置。保存 WebDAV 配置后，后台会自动生成**专属 cron 令牌**和可直接粘贴的配置片段：

```json
{
  "schedules": [
    {
      "name": "navbox-webdav-backup",
      "cron": "0 4 * * *",
      "timezone": "Asia/Shanghai",
      "path": "/api/cron/backup",
      "method": "POST",
      "payload": { "token": "你的令牌" }
    }
  ]
}
```

> ⚠️ **平台限制：EdgeOne 定时任务最小间隔为一天**，不支持小时级 cron。若需要小时级备份，请用机制①。
> cron 为 5 段格式（分 时 日 月 周），不支持秒级。每次部署会自动对比配置，移除的任务会被停止。

**建议两者都配上**：cron 保证即使无人访问也每天备份一次，流量驱动保证活跃站点备份更及时。

### 备份内容与文件

- 内容：分组 + 书签 + 外观设置（**不含**管理员密码、不含 WebDAV 密码）
- 每次备份生成 `navbox-<时间戳>.json`，同时更新 `navbox-latest.json`
- 超过「保留份数」后自动删除最旧的备份
- 后台可查看最近 30 条备份日志（成功 / 失败 / 触发方式 / 数据量）

### 手动备份与恢复

- **立即备份**：手动触发一次
- **列出云端备份文件**：读取 WebDAV 目录下所有 `.json`，可对任意一份执行恢复
- **从最新备份恢复**：直接用 `navbox-latest.json` 覆盖当前数据

> 恢复是**覆盖**操作且不可撤销，执行前建议先手动备份一次。

## 平台限制与注意事项

以下均为 EdgeOne 平台的硬性限制，代码已做适配，但使用时需知道：

| 项目 | 限制 | 本项目的应对 |
|---|---|---|
| Edge Function 请求体 | **1 MB** | 上传背景图会先在浏览器压缩到 1600px/0.82 质量；仍超限则提示改用图床外链 |
| KV key 命名 | 仅数字、字母、下划线，≤512B | 所有键名统一用 `navbox_` 前缀 + 驼峰，无特殊字符 |
| KV value | ≤ 25 MB | 背景图建议用图床外链而非上传，避免占用容量 |
| Edge Function CPU | 单次 200ms（不含 I/O） | 密码哈希 60000 轮 PBKDF2，实测在此范围内；点击计数用 `waitUntil` 异步写 |
| KV 一致性 | **最终一致**，边缘缓存最长 60s | 写入节点立即生效；异地节点最长 60s 后可见。多设备同时改数据可能短暂看到旧值 |
| 定时任务 | 最小间隔一天 | 小时级自动备份改用流量驱动机制 |
| 函数代码包 | ≤ 5 MB | 当前后端单文件约 60KB，远低于限制 |
| KV 开通 | 白名单申请制 | 需先在控制台申请，见「部署步骤一」 |

**关于 KV 60 秒延迟**：在后台改完设置后，如果你所在的边缘节点刚缓存过旧数据，前台可能最长 60 秒才刷新。后台界面通过本地 patch 立即同步，不受影响；其他访客稍后自动看到新值。

## 安全说明

- **密码存储**：PBKDF2-SHA256，60000 轮迭代 + 每账号独立随机盐，不存明文
- **会话**：HMAC-SHA256 签名令牌，`HttpOnly` + `SameSite=Lax`，线上 HTTPS 自动加 `Secure`，有效期 7 天
- **改密即失效**：修改密码会递增 tokenVersion，使所有旧会话立即失效
- **登录限流**：同一 IP 连续失败 5 次锁定 10 分钟
- **私密书签**：在 `/api/bootstrap` 出口按登录态过滤，未登录拿不到数据，不依赖前端隐藏
- **XSS 防护**：所有用户内容输出前统一转义；搜索高亮先转义再包裹标记
- **输入校验**：URL 协议白名单、长度截断、数值夹紧到合法区间、枚举值非法则回退默认
- **WebDAV 凭据**：仅存于 KV，不写入备份文件，接口响应只回显 `passwordSet` 布尔值
- **Cron 令牌**：调用 `/api/cron/backup` 必须携带正确令牌，常数时间比较防时序攻击

### 需要你注意的两点

1. **单管理员设计**：本系统只有一个管理员账号，不支持多用户、不做权限分级
2. **忘记密码**：可在 EdgeOne 控制台 KV 数据管理中删除键 `navbox_admin`，下次请求时系统会自动重建默认账号 `admin/admin123`，**书签与设置数据不受影响**

## 常见问题

**Q：页面提示「后端存储未就绪」**
A：按顺序排查：

1. 到 **项目 → KV 存储** 确认已绑定命名空间，变量名建议填 `NAV_KV`（代码已兼容任意变量名，且同时支持全局作用域与环境变量两种注入方式）。
2. **绑定后必须重新部署**——绑定关系不会热生效到已有部署。
3. 浏览器打开 `https://你的域名/api/debug/env` 查看运行时实际看到的键名：
   - `kvBound: true` 且 `kvSource` 有值 → KV 已识别，问题在别处（见下方其他条目）；
   - `kvBound: false` → 把返回的 `envKeys` / `globalKeys` 与控制台变量名对照；若都为空，说明平台未注入绑定，回到第 1、2 步检查绑定与部署。
4. 若 `envKeys` 里有变量名但 `kvBound` 仍为 false，说明该对象不具备 KV 接口（可能被绑成了普通环境变量字符串），请到控制台改用「KV 存储 → 绑定命名空间」，而不是项目环境变量。

**Q：网站图标显示为首字文字块**
A：说明所有图标源都抓取失败。常见原因：目标站点无 favicon、图标源被墙（Google 源需可访问 Google）、或站点有防盗链。可在后台「外观 → 图标抓取源」换一个源试试，或为该书签手动指定图标。

**Q：上传背景图提示超过 1MB**
A：平台限制请求体 1MB。代码已自动压缩，若原图特别大仍可能超限。建议改用「图床外链」方式，无大小限制且不占 KV 容量。

**Q：WebDAV 测试连接返回 401**
A：坚果云等服务需要「应用密码 / 安全设置密码」，不是网页登录密码。到网盘的安全设置里生成一个。

**Q：改了设置但前台没变**
A：KV 是最终一致的，边缘缓存最长 60 秒。后台界面已即时同步；刷新前台页面或稍等即可。

**Q：定时任务没执行**
A：确认 ① `edgeone.json` 的 `schedules.path` 指向 `/api/cron/backup`；② `payload.token` 填了后台生成的真实令牌；③ 改完 `edgeone.json` 需重新部署才生效。

**Q：想换站点标题、页脚**
A：后台 → **外观** 标签页，「站点信息」区块。页脚里直接写 http(s) 链接会自动变成可点击链接。
